# 🎓 MSU Scoring (OMR Grading System & Mobile App)

ยินดีต้อนรับสู่คลังรหัสพัฒนา (Repository) ของระบบตรวจข้อสอบปรนัย (OMR Grading System) มหาวิทยาลัยมหาสารคาม (MSU) 

โปรเจกต์นี้แบ่งออกเป็น 2 ส่วนหลักๆ ตามโฟลเดอร์ดังนี้:

---

## 📂 โครงสร้างโปรเจกต์

### 1. 🌐 [msu_scoring_web](file:///c:/Final%20Project/msu_scoring_web) (Web Application)
ระบบตรวจข้อสอบปรนัยแบบ Web App ดั้งเดิมที่รันบน Docker + PHP (Apache) + SQLite/MySQL มีระบบสแกนกระดาษคำตอบผ่านกล้องเว็บแคม และสรุปคะแนนออกมาเป็นไฟล์ PDF/CSV
- **รายละเอียดการใช้งานและวิธีติดตั้ง:** อ่านได้ที่ [msu_scoring_web/README.md](file:///c:/Final%20Project/msu_scoring_web/README.md)

### 2. 📱 [msu_scoring_app](file:///c:/Final%20Project/msu_scoring_app) (Mobile Application)
แอปพลิเคชันตรวจข้อสอบปรนัยเวอร์ชันมือถือ (Flutter Mobile App) ที่กำลังอยู่ในระหว่างการพัฒนา เพื่อเพิ่มความคล่องตัวในการใช้งานบนสมาร์ตโฟนและเพิ่มความเสถียรในการใช้กล้องตรวจข้อสอบ
- **รายละเอียดการพัฒนา:** อ่านรายละเอียดด้านในโฟลเดอร์ [msu_scoring_app](file:///c:/Final%20Project/msu_scoring_app)
